Vlastní propojení s Google

Aplikace se k tvému Google Kalendáři připojuje přes přihlášení Googlem. Potřebuje k tomu Client ID (je veřejné, není to heslo). Žádný API klíč ani tajný klíč se nepoužívá. Svoje Client ID si zdarma vyrobíš za asi 10 minut podle návodu níže.

Návod: jak získat vlastní Client ID
  1. Otevři console.cloud.google.com a přihlas se Google účtem, jehož kalendář chceš používat.
  2. Nahoře vlevo klepni na výběr projektu a vytvoř Nový projekt (název třeba „Směnový kalendář“).
  3. Menu ☰ → API a služby → Knihovna. Vyhledej Google Calendar API a klepni na Povolit.
  4. Menu ☰ → API a služby → Obrazovka souhlasu OAuth (nově „Google Auth Platform“). Zvol typ Externí, vyplň název aplikace a svůj e‑mail.
  5. V části Přístup k datům (Scopes) přidej oprávnění …/auth/calendar.events a …/auth/calendar.calendarlist.readonly.
  6. V části Cílová skupina (Audience) nech stav „Testování“ a přidej svůj Gmail mezi Testovací uživatele. Pro osobní použití stačí, publikovat ani ověřovat aplikaci nemusíš.
  7. API a služby → Přihlašovací údaje → Vytvořit přihlašovací údaje → ID klienta OAuth. Typ aplikace: Webová aplikace.
  8. U Oprávněné zdroje JavaScriptu přidej adresu, ze které tuto stránku otevíráš: (bez lomítka na konci a bez cesty). „Oprávněné identifikátory URI přesměrování“ nech prázdné.
  9. Po vytvoření zkopíruj ID klienta (končí na .apps.googleusercontent.com), vlož ho do pole nahoře a klepni na Uložit Client ID.
  10. Vrať se do importu nebo úprav událostí a klepni na Přihlásit se přes Google. Google zobrazí upozornění „Aplikace není ověřena“: klepni na Rozšířené → Pokračovat (je to tvoje vlastní aplikace) a povol přístup ke kalendáři.

Přihlášení platí asi hodinu, potom se Google zeptá znovu. Aplikace do kalendáře zapisuje jen to, co sám v okně „Události v Google Kalendáři“ upravíš, a k ničemu jinému v účtu nepřistupuje. Přístup můžeš kdykoli zrušit na myaccount.google.com → Zabezpečení → Aplikace třetích stran. Stránku je nutné otevírat přes https (ne ze souboru).

Mám už Client ID od někoho jiného

Použít jde i výchozí propojení. Majitel projektu v něm ale musí tvůj Gmail přidat mezi testovací uživatele (Google Cloud → Obrazovka souhlasu OAuth → Cílová skupina → Testovací uživatelé; nejvýš 100 lidí). Bez toho Google přihlášení zablokuje. Doporučené je mít vlastní Client ID.

Import z Google Kalendáře

Vybrané události se přidají na konec poznámky u příslušného dne. Import události jen čte, v kalendáři nic nemění ani nemaže (úpravy jsou v okně „Události v Google Kalendáři“).

Události v Google Kalendáři

Tady upravuješ, přidáváš a mažeš události přímo v Google Kalendáři, včetně těch, které se opakují každý rok (třeba narozeniny). Změna opakované události platí pro všechny její výskyty. Kalendáře jen pro čtení se tu nenabízejí.

Nová událost

Každoroční události (např. narozeniny) můžeš zobrazit i v kalendáři aplikace - ukazují se pak každý rok bez přihlášení. Použij tlačítko s kalendářem u události, nebo všechny najednou.

Nemoc

Označí nemoc od tohoto dne do zvoleného data (včetně volných dnů - počítají se kalendářní dny). Prvních 14 dní platí zaměstnavatel náhradu mzdy za zameškané směny, od 15. dne je nemocenské od ČSSZ.

Změnit směnu
